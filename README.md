# KOMA Локальная

Библиотека и читалка — и ничего больше. Ни каталога, ни онлайн-движков, ни
обновлений из сети: у приложения **нет разрешения на интернет**, поэтому
«сходить в сеть» оно не может даже случайно.

## Что внутри

* **Читалка** — проверенная страница `koma-web.html` (собирается из частей
  `part*.js` + `part1.html`), целиком внутри АПК: ORT WASM и словарь вшиты.
  Читает **видимую полосу** страницы, страница за страницей, а не весь лист.
* **Распознавание — нативное** (`OcrEngine`): ONNX Runtime для Android, модели
  `det.onnx` + `rec.onnx` + азбука лежат в АПК и раскладываются при первом
  запуске. Выбирать файлы не нужно.
* **Порядок и склейка реплик — нативные** (`ReadEngine` через мост `KomaRead`).
* **Голос** — системный Android TTS за мостом `KomaSpeech` (в WebView нет
  Web Speech API вообще).
* **Библиотека** — файлы с устройства: CBZ/ZIP, папка, отдельные страницы.
  Хранится в IndexedDB страницы на постоянном адресе
  `https://appassets.androidplatform.net/web/koma-web.html`.

## Чего здесь нет намеренно

`GlensEngine` (Google Lens), `KomaLensBridge`, `Updater` (обновление с GitHub),
каталог, Gemini/OpenRouter/OwOCR/Space Bunny. Мост `KomaApp` остался только с
версией и перезагрузкой: `checkUpdate` честно отвечает «локальная сборка».

## Сборка

```bash
bash build.sh          # собрать koma-web.html из частей
cd apk && gradle assembleDebug
```

Или просто запушить: `.github/workflows/apk.yml` соберёт АПК на ранере и
проверит, что онлайн-путей не осталось (ни INTERNET в манифесте, ни Lens, ни
загрузчика обновлений в исходниках).

## Тесты

```bash
node tools/test_glue.cjs        # слово, разорванное переносом: «ВЛ ИТЬ» → «ВЛИТЬ»
python3 tools/measure.py --image data/real/dense-a.jpg --expected data/real/dense-expected.json
```

`tools/test_glue.cjs` берёт НАСТОЯЩИЙ вшитый словарь (part0-dict.js) и настоящий
исходник функции из part3.js, поэтому проверяет то, что реально попадёт в голос.
`tools/measure.py` меряет время распознавания и сверяет реплики с эталоном по
словам (CER, пропуски).

## Установка

`applicationId` тот же (`net.koma.reader`) и ключ подписи тот же, что у прежней
`koma-reader`, поэтому ставится поверх, книги и настройки остаются.
